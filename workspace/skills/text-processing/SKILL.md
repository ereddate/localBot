# 文本处理技能 📝

## 何时使用
- 需要分析文本内容时
- 需要转换文本格式时
- 需要提取文本信息时
- 需要处理大量文本时
- 需要文本清洗时

## 何时不使用
- 文本内容简单
- 不需要处理
- 手动处理更高效

## 输出格式
- 处理后的文本
- 分析结果
- 统计数据
- 提取的信息

## 使用流程
1. 读取文本内容
2. 分析文本特征
3. 执行处理操作
4. 验证处理结果
5. 生成处理报告
6. 保存处理结果

## 示例场景

### 场景1：文本清洗
用户请求："清洗这个文本文件"
执行步骤：
1. 读取文本内容
2. 去除特殊字符
3. 统一格式
4. 去除重复行
5. 保存清洗结果
6. 生成处理报告

### 场景2：文本分析
用户请求："分析这段文本的关键词"
执行步骤：
1. 读取文本内容
2. 分词处理
3. 统计词频
4. 提取关键词
5. 生成分析报告
6. 提供可视化

### 场景3：格式转换
用户请求："将Markdown转换为HTML"
执行步骤：
1. 读取Markdown文件
2. 解析Markdown语法
3. 转换为HTML
4. 格式化HTML
5. 保存HTML文件
6. 验证转换结果

## 工具依赖
- `file_read`: 读取文本文件
- `file_write`: 写入文本文件
- `text_analyze`: 分析文本
- `text_transform`: 转换文本
- `regex_match`: 正则匹配
