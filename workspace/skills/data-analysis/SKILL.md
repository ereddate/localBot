# 数据分析技能 📊

## 何时使用
- 需要读取和分析CSV或JSON数据文件时
- 需要生成统计报告和数据摘要时
- 需要处理和转换数据格式时
- 需要搜索和过滤数据时
- 需要计算数据统计指标时

## 何时不使用
- 需要实时数据可视化（使用专门的BI工具）
- 处理超大数据集（GB级别）
- 需要复杂的机器学习分析

## 输出格式
- 数据统计摘要
- 过滤后的数据结果
- 计算指标和趋势分析
- 文本格式的数据报告

## 使用流程
1. 使用 `file_read` 或 `csv_read` 读取数据文件
2. 使用 `text_analysis` 分析数据内容和结构
3. 使用 `json_parse` 或 `csv_parse` 解析数据
4. 执行数据过滤、转换和计算
5. 使用 `file_write` 或 `json_write` 保存结果

## 示例场景

### 场景1：分析销售数据
用户请求："帮我分析这个销售数据文件"
执行步骤：
1. 读取CSV文件：`csv_read` 工具
2. 计算统计信息：总销售额、平均销售额、最高/最低销售额
3. 按产品分类汇总
4. 生成分析报告

### 场景2：数据清洗
用户请求："清理这个数据文件中的重复项"
执行步骤：
1. 读取数据文件
2. 识别重复记录
3. 删除重复项
4. 保存清洗后的数据

### 场景3：数据转换
用户请求："将这个CSV文件转换为JSON格式"
执行步骤：
1. 读取CSV文件
2. 解析CSV数据
3. 转换为JSON格式
4. 保存为JSON文件

## 工具依赖
- `file_read`: 读取数据文件内容
- `csv_read`: 解析CSV格式数据
- `json_read`: 解析JSON格式数据
- `text_analysis`: 分析文本数据
- `json_write`: 写入JSON格式数据
- `csv_write`: 写入CSV格式数据
- `file_write`: 保存处理结果

## 注意事项
- 确保数据文件格式正确
- 注意数据类型转换
- 处理缺失值和异常值
- 保留原始数据备份
- 验证分析结果的准确性

## 最佳实践
- 先查看数据样本了解结构
- 记录数据处理步骤
- 验证数据完整性
- 使用适当的统计方法
- 提供清晰的分析报告
