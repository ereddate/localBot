# 系统管理技能 ⚙️

## 何时使用
- 需要监控系统状态时
- 需要配置系统参数时
- 需要管理系统服务时
- 需要优化系统性能时
- 需要诊断系统问题时

## 何时不使用
- 不具备管理权限
- 操作过于危险
- 需要专业管理员

## 输出格式
- 系统状态报告
- 配置文件
- 监控数据
- 操作日志

## 使用流程
1. 分析管理需求
2. 检查系统状态
3. 确定操作方案
4. 执行管理操作
5. 验证操作结果
6. 生成管理报告

## 示例场景

### 场景1：系统监控
用户请求："监控系统资源使用情况"
执行步骤：
1. 检查CPU使用率
2. 检查内存使用情况
3. 检查磁盘空间
4. 检查网络状态
5. 生成监控报告
6. 提供优化建议

### 场景2：服务管理
用户请求："重启Web服务器服务"
执行步骤：
1. 检查服务状态
2. 停止服务
3. 等待服务停止
4. 启动服务
5. 验证服务状态
6. 生成操作日志

### 场景3：系统优化
用户请求："优化系统性能"
执行步骤：
1. 分析系统瓶颈
2. 检查配置参数
3. 提供优化建议
4. 应用优化配置
5. 验证优化效果
6. 生成优化报告

## 工具依赖
- `shell_execute`: 执行系统命令
- `system_info`: 获取系统信息
- `process_list`: 列出进程
- `service_manage`: 管理服务
- `log_analyze`: 分析日志

## 注意事项
- 检查操作权限
- 备份重要配置
- 验证操作安全性
- 监控操作结果
- 记录操作日志
- 准备回滚方案

## 最佳实践
- 使用最小权限原则
- 定期备份配置
- 监控系统状态
- 及时更新系统
- 优化资源配置
- 记录变更历史
