# 业务自动化技能 ⚙️

## 何时使用
- 需要定时执行任务时
- 需要编排复杂工作流时
- 需要监控系统状态时
- 需要自动化重复性任务时
- 需要处理业务流程时

## 何时不使用
- 需要人工决策的任务
- 涉及敏感数据的操作
- 需要实时交互的场景

## 输出格式
- 任务执行结果
- 工作流状态报告
- 系统监控数据
- 自动化日志

## 使用流程
1. 分析业务需求
2. 设计自动化流程
3. 配置任务调度
4. 设置监控和告警
5. 执行和监控自动化
6. 记录执行日志

## 示例场景

### 场景1：定时数据备份
用户请求："设置每天凌晨2点自动备份数据"
执行步骤：
1. 创建备份脚本
2. 配置定时任务
3. 设置备份目录
4. 添加日志记录
5. 测试备份流程

### 场景2：工作流编排
用户请求："创建一个数据处理工作流"
执行步骤：
1. 定义工作流步骤
2. 配置步骤依赖关系
3. 设置错误处理
4. 执行工作流
5. 监控执行状态

### 场景3：系统监控
用户请求："监控服务器CPU使用率"
执行步骤：
1. 编写监控脚本
2. 设置采样间隔
3. 配置告警阈值
4. 记录监控数据
5. 发送告警通知

## 工具依赖
- `shell_execute`: 执行自动化脚本
- `process_list`: 监控进程状态
- `system_info`: 获取系统信息
- `file_read`: 读取配置文件
- `file_write`: 保存脚本和日志
- `http_post`: 发送通知和告警

## 注意事项
- 确保脚本安全性
- 添加适当的错误处理
- 记录详细的执行日志
- 设置合理的超时时间
- 避免资源泄漏
- 测试自动化流程
