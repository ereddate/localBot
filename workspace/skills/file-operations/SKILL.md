# 文件操作技能 📁

## 何时使用
- 需要读取文件内容时
- 需要写入文件时
- 需要管理目录结构时
- 需要批量处理文件时
- 需要搜索文件时

## 何时不使用
- 文件不存在
- 权限不足
- 文件正在使用中

## 输出格式
- 操作结果
- 文件内容
- 文件列表
- 操作日志

## 使用流程
1. 确定操作类型
2. 验证文件路径
3. 检查操作权限
4. 执行文件操作
5. 验证操作结果
6. 记录操作日志

## 示例场景

### 场景1：批量重命名文件
用户请求："把这些文件按日期重命名"
执行步骤：
1. 列出目标文件
2. 提取文件信息
3. 生成新文件名
4. 执行重命名操作
5. 验证结果
6. 生成操作报告

### 场景2：搜索文件内容
用户请求："在所有文件中搜索这个关键词"
执行步骤：
1. 确定搜索范围
2. 遍历文件目录
3. 读取文件内容
4. 搜索关键词
5. 记录匹配结果
6. 生成搜索报告

### 场景3：清理临时文件
用户请求："清理项目中的临时文件"
执行步骤：
1. 识别临时文件
2. 列出待删除文件
3. 确认删除操作
4. 执行删除
5. 验证清理结果
6. 生成清理报告

## 工具依赖
- `file_read`: 读取文件内容
- `file_write`: 写入文件内容
- `file_list`: 列出文件
- `file_delete`: 删除文件
- `file_copy`: 复制文件
- `file_move`: 移动文件
- `file_stat`: 获取文件信息
