# 代码生成技能 💻

## 何时使用
- 需要生成代码模板时
- 需要创建代码片段时
- 需要自动生成样板代码时
- 需要生成测试代码时
- 需要生成配置文件时

## 何时不使用
- 需要手动优化的代码
- 涉及复杂业务逻辑的代码
- 需要人工审查的关键代码

## 输出格式
- 生成的代码文件
- 代码模板
- 使用说明
- 依赖说明

## 使用流程
1. 分析代码需求
2. 选择合适的模板
3. 配置代码参数
4. 生成代码
5. 验证代码正确性
6. 提供使用说明

## 工具依赖
- `file_write`: 写入生成的代码
- `file_read`: 读取模板文件
- `shell_execute`: 运行代码格式化工具
- `http_get`: 获取代码模板
