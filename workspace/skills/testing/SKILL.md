# 测试技能 ✅

## 何时使用
- 需要编写测试用例时
- 需要执行测试时
- 需要生成测试报告时
- 需要分析测试结果时
- 需要提高代码覆盖率时

## 何时不使用
- 代码已经充分测试
- 测试环境不可用
- 测试用例不明确

## 输出格式
- 测试用例代码
- 测试执行结果
- 测试报告
- 覆盖率报告

## 使用流程
1. 分析测试需求
2. 设计测试用例
3. 编写测试代码
4. 执行测试
5. 分析测试结果
6. 生成测试报告

## 示例场景

### 场景1：单元测试
用户请求："为这个函数编写单元测试"
执行步骤：
1. 分析函数功能
2. 识别测试场景
3. 编写测试用例
4. 生成测试代码
5. 执行测试
6. 生成测试报告

### 场景2：集成测试
用户请求："测试API接口"
执行步骤：
1. 分析API文档
2. 设计测试场景
3. 编写测试用例
4. 执行API测试
5. 验证响应结果
6. 生成测试报告

### 场景3：性能测试
用户请求："测试接口性能"
执行步骤：
1. 设计性能测试方案
2. 配置测试参数
3. 执行性能测试
4. 收集性能数据
5. 分析性能瓶颈
6. 生成性能报告

## 工具依赖
- `file_read`: 读取代码文件
- `file_write`: 写入测试文件
- `shell_execute`: 运行测试命令
- `http_get`: API测试
- `http_post`: API测试
