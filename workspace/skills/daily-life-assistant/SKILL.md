# 生活助手技能 🏠

## 何时使用
- 需要查询天气信息时
- 需要管理日程和提醒时
- 需要搜索生活服务时
- 需要获取实用信息时
- 需要处理日常事务时

## 何时不使用
- 需要实时支付功能
- 涉及个人隐私信息
- 需要人工客服支持

## 输出格式
- 天气预报信息
- 日程安排列表
- 生活服务建议
- 实用工具结果

## 使用流程
1. 理解用户需求
2. 收集必要信息
3. 调用相应的API或工具
4. 处理返回结果
5. 提供友好的回复

## 示例场景

### 场景1：查询天气
用户请求："查询北京今天的天气"
执行步骤：
1. 识别地点（北京）
2. 调用天气API
3. 解析天气数据
4. 格式化输出信息
5. 提供天气建议

### 场景2：日程管理
用户请求："帮我添加一个明天的会议提醒"
执行步骤：
1. 提取会议信息（时间、主题）
2. 格式化日程条目
3. 保存到日程文件
3. 确认添加成功

### 场景3：生活服务搜索
用户请求："帮我找附近的餐厅"
执行步骤：
1. 识别位置和需求
2. 搜索相关服务
3. 整理搜索结果
4. 提供推荐列表

## 工具依赖
- `web_fetch`: 获取网络信息
- `http_get`: 调用API服务
- `file_read`: 读取本地数据
- `file_write`: 保存日程和记录
- `json_parse`: 解析API响应
- `text_analysis`: 分析用户需求
