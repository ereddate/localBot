# Shell命令技能 💻

## 何时使用
- 需要执行系统命令时
- 需要管理进程时
- 需要配置系统时
- 需要批量操作时
- 需要系统信息时

## 何时不使用
- 命令过于危险
- 需要交互式操作
- 权限不足

## 输出格式
- 命令输出
- 执行结果
- 错误信息
- 系统信息

## 使用流程
1. 分析命令需求
2. 构建安全命令
3. 验证命令安全性
4. 执行命令
5. 解析输出结果
6. 记录执行日志

## 示例场景

### 场景1：系统信息查询
用户请求："查看系统CPU使用情况"
执行步骤：
1. 构建查询命令
2. 执行命令
3. 解析输出
4. 格式化结果
5. 提供分析说明
6. 生成报告

### 场景2：进程管理
用户请求："查看并终止占用端口的进程"
执行步骤：
1. 查找占用端口的进程
2. 显示进程信息
3. 确认终止操作
4. 执行终止命令
5. 验证结果
6. 生成操作日志

### 场景3：批量文件操作
用户请求："批量修改文件权限"
执行步骤：
1. 列出目标文件
2. 构建chmod命令
3. 执行批量操作
4. 验证权限修改
5. 生成操作报告
6. 记录操作日志

## 工具依赖
- `shell_execute`: 执行Shell命令
- `process_list`: 列出进程
- `process_kill`: 终止进程
- `system_info`: 获取系统信息
- `env_var`: 环境变量操作
