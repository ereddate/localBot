# 调试技能 🐛

## 何时使用
- 代码出现错误时
- 程序行为异常时
- 需要定位问题时
- 需要分析错误日志时
- 需要性能分析时

## 何时不使用
- 代码正常运行
- 错误已经解决
- 问题已经定位

## 输出格式
- 调试报告
- 错误分析
- 修复建议
- 测试用例

## 使用流程
1. 收集错误信息
2. 分析错误原因
3. 定位问题位置
4. 提供修复方案
5. 验证修复效果
6. 生成调试报告

## 示例场景

### 场景1：调试运行时错误
用户请求："程序报错了，帮我看看"
执行步骤：
1. 读取错误日志
2. 分析错误类型
3. 定位错误位置
4. 检查相关代码
5. 提供修复建议
6. 生成调试报告

### 场景2：调试性能问题
用户请求："这个函数运行太慢了"
执行步骤：
1. 分析函数逻辑
2. 识别性能瓶颈
3. 检查算法复杂度
4. 提供优化建议
5. 生成优化方案
6. 提供性能对比

### 场景3：调试逻辑错误
用户请求："结果不对，帮我找问题"
执行步骤：
1. 分析预期结果
2. 检查实际结果
3. 对比差异原因
4. 定位逻辑错误
5. 提供修复代码
6. 生成测试用例

## 工具依赖
- `file_read`: 读取代码文件
- `shell_execute`: 运行调试工具
- `log_analyze`: 分析日志文件
- `error_trace`: 追踪错误堆栈

## 注意事项
- 保持冷静客观

- 分析根本原因
- 提供具体建议
- 验证修复方案
- 记录调试过程
