# 数据可视化技能 📊

## 何时使用
- 需要展示数据趋势时
- 需要分析数据分布时
- 需要创建数据报告时
- 需要可视化复杂数据时
- 需要生成交互式图表时

## 何时不使用
- 数据量过小
- 数据质量差
- 不需要可视化展示

## 输出格式
- 图表文件（PNG、SVG等）
- 交互式图表代码
- 数据分析报告
- 可视化配置

## 使用流程
1. 读取数据文件
2. 分析数据特征
3. 选择合适的图表类型
4. 配置图表参数
5. 生成可视化图表
6. 保存图表文件

## 示例场景

### 场景1：生成折线图
用户请求："为这组销售数据生成折线图"
执行步骤：
1. 读取销售数据
2. 提取时间和数值
3. 配置折线图样式
4. 添加标题和标签
5. 生成图表文件
6. 提供图表说明

### 场景2：生成柱状图
用户请求："比较不同产品的销售量"
执行步骤：
1. 读取产品数据
2. 提取产品名称和销量
3. 配置柱状图样式
4. 添加颜色和标签
5. 生成图表文件
6. 提供分析说明

### 场景3：生成饼图
用户请求："展示市场份额分布"
执行步骤：
1. 读取市场份额数据
2. 计算百分比
3. 配置饼图样式
4. 添加图例和标签
5. 生成图表文件
6. 提供数据解读

## 工具依赖
- `file_read`: 读取数据文件
- `csv_parse`: 解析CSV数据
- `json_parse`: 解析JSON数据
- `data_analyze`: 分析数据特征
- `file_write`: 保存图表文件

## 注意事项
- 选择合适的图表类型
- 确保数据准确性
- 使用清晰的标签
- 考虑颜色对比度
- 添加必要的说明
- 保持图表简洁
