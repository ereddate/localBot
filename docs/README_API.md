# LocalBot - 本地AI智能助手

## 功能特点

### 🚀 核心能力
- **多AI模型路由**: 支持国内外主流AI模型（OpenAI、百度文心一言、腾讯混元、智谱AI、硅基流动等）
- **国产AI大模型支持**: 完整集成国内主流AI服务商模型
- **业务流程自动化**: 自动分析用户需求并执行相应业务流程
- **本地技能系统**: 丰富的内置工具和技能
- **离线处理能力**: 支持离线环境下的部分功能执行
- **统一API接口**: 提供标准化的RESTful API接口

### 🏢 企业级功能
- **企业税务规划**: 自动化企业税务优化方案
- **个人税务规划**: 个性化个人税务筹划服务
- **CRM集成**: 客户关系管理自动化
- **销售流程管理**: 智能销售流程跟踪与管理
- **财务分析**: 自动财务数据分析与报告生成

### 🏠 家庭自动化
- **智能家居控制**: 集成各类智能家居设备
- **家庭财务管理**: 个人和家庭财务规划
- **日程管理**: 智能日程安排和提醒
- **生活助手**: 日常生活相关任务自动化

### 🔧 技能系统
- **天气查询**: 实时天气信息获取
- **新闻聚合**: 最新资讯聚合服务
- **翻译工具**: 多语言实时翻译
- **计算器**: 复杂数学计算
- **密码生成**: 安全密码生成器
- **地图定位**: 地理位置服务
- **日历事件**: 日程管理和提醒
- **待办事项**: 任务管理功能
- **图像处理**: 图像识别和处理
- **音频处理**: 音频分析和处理
- **文档生成**: 自动文档生成
- **数据分析**: 数据分析和可视化

## 统一API接口

### API端点

#### 健康检查
- `GET /health` - 检查API服务状态

#### 消息处理
- `POST /api/v1/message` - 处理用户消息
  - 请求体: `{ "sessionId": "string", "content": "string" }`
  - 响应: 标准化API响应格式

#### 会话管理
- `GET /api/v1/session/:sessionId` - 获取特定会话信息
- `GET /api/v1/sessions` - 获取所有会话
- `DELETE /api/v1/session/:sessionId` - 关闭指定会话

#### 工具执行（预留）
- `POST /api/v1/tool/:toolName` - 执行特定工具（待实现）

#### 业务流程执行（预留）
- `POST /api/v1/process/:processType` - 执行业务流程（待实现）

### 响应格式

成功响应:
```json
{
  "code": 200,
  "message": "Success message",
  "data": {},
  "timestamp": 1234567890,
  "requestId": "unique-request-id"
}
```

错误响应:
```json
{
  "code": 400,
  "message": "Error message",
  "details": "Detailed error information",
  "timestamp": 1234567890,
  "requestId": "unique-request-id"
}
```

## 使用方法

### 1. 环境设置
复制 `.env.example` 文件并命名为 `.env`，然后填入相应的API密钥。

### 2. 安装依赖
```bash
npm install
```

### 3. 构建项目
```bash
npm run build
```

### 4. 启动服务
```bash
npm start
```

### 5. 启动API服务
```bash
npx ts-node api-test.ts
```

## 设计理念

LocalBot旨在成为真正的本地AI智能助手，具备以下特点：

1. **智能化**: 能够分析用户意图并自动选择合适的处理方式
2. **自主性**: 具备自我决策能力，可根据情况选择最优执行路径
3. **扩展性**: 易于添加新的技能和功能模块
4. **本土化**: 特别优化对中文及国内服务的支持
5. **实用性**: 专注于解决实际工作和生活中的问题
